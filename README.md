# Question Paper Intelligence

An intelligent platform for analyzing question papers — detecting repeated, paraphrased, and conceptually similar questions across exam papers using NLP, vector embeddings, and AI agents.

## Tech Stack

| Layer      | Technology                                          |
|------------|-----------------------------------------------------|
| Frontend   | Next.js 14, React 18, TailwindCSS, TanStack Query   |
| Backend    | FastAPI, SQLAlchemy 2, Alembic, Celery, Pydantic v2  |
| Database   | PostgreSQL 16 + pgvector                             |
| Cache/Queue| Redis 7 (only when `TASK_QUEUE=celery`)              |
| Storage    | Local filesystem                                     |
| AI/NLP     | Sentence Transformers, BM25                          |
| Infra      | Docker Compose                                       |

## Getting Started

### 1. Start infrastructure

```bash
docker compose up -d postgres redis
```

| Service    | Port   | Credentials                                   |
|------------|--------|-----------------------------------------------|
| PostgreSQL | `5432` | user: `qpi`, password: `secret`, db: `qpi_db` |
| Redis      | `6379` | —                                             |

(MinIO is also defined in the compose file but the backend currently only implements local file storage.)

### 2. Backend

All backend commands run from the `backend/` directory.

```bash
cd backend
py -3.13 -m venv .venv            # macOS/Linux: python3.13 -m venv .venv
.venv\Scripts\activate            # macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
pip install -r requirements-ml.txt   # optional but recommended: semantic embeddings

cp .env.example .env              # then set JWT_SECRET_KEY
alembic upgrade head              # create the schema (pgvector extension + HNSW index)
python -m scripts.seed            # departments, demo users, syllabi, historical archive, sample PDFs
uvicorn app.main:app --reload --port 8000
```

- API docs: http://localhost:8000/api/v1/docs · Health: http://localhost:8000/health
- The first analysis downloads the `all-mpnet-base-v2` model (~420 MB) if it is not cached. Without
  `requirements-ml.txt` the backend falls back to a built-in lexical *hashing* embedder
  (`EMBEDDING_PROVIDER=hashing`), which catches verbatim/lightly reworded repeats but not deep paraphrases.

**Celery (optional).** By default analysis runs inside the API process (`TASK_QUEUE=background`).
To use a worker instead, set `TASK_QUEUE=celery` in `.env` and run, in another terminal:

```bash
celery -A app.core.celery_app worker --loglevel=info --pool=solo   # --pool=solo is required on Windows
```

### 3. Frontend

```bash
cd frontend
npm install
npm run dev          # http://localhost:3000
```

The Next.js server proxies `/api/v1/*` to `BACKEND_URL` (default `http://localhost:8000`, see
`frontend/.env.example`), so session cookies are first-party and no CORS setup is needed.

## How analysis works

1. **Upload** (`POST /api/v1/papers/upload`): PDF/DOCX ≤ 25 MB, validated by content (magic bytes), stored
   under `backend/uploads/`, queued (`202`). The UI polls `GET /papers/{id}/status`.
2. **Parse**: PyMuPDF / python-docx text → questions and sub-questions (numbering, sections, marks).
   Encrypted, corrupt or question-less documents fail with a clear message.
3. **Classify**: question format, Bloom's level (verb heuristics) and syllabus unit (unit keywords).
4. **Embed & match**: 768-d embeddings; pgvector HNSW finds candidates among *archived* papers of the same
   course (falling back to the department). Composite score = 0.7 × cosine + 0.3 × BM25 (normalised),
   tiered Exact ≥ 0.90 / Paraphrased ≥ 0.75 / Conceptual ≥ 0.60.
5. **Report**: marks-weighted originality score, unit coverage, 5-year topic saturation, conceptual gaps
   and up to 5 prioritised recommendations.

The archive consists of papers uploaded with *Add to historical exam archive* (archival/system admins) plus
drafts that were **approved** from their report page.

## API overview (`/api/v1`)

| Method | Path | Purpose |
|---|---|---|
| POST | `/auth/register`, `/auth/login`, `/auth/refresh`, `/auth/logout` | Cookie session auth |
| POST | `/auth/token` | OAuth2 password flow (bearer token for API clients / Swagger) |
| GET | `/auth/me` | Current user |
| GET | `/departments` (public), `/courses` | Catalog |
| GET/PUT | `/courses/{id}/syllabus` | Syllabus units (PUT: dept head / admins) |
| POST | `/papers/upload` | Upload & queue analysis |
| GET | `/papers?page&limit&search&status&sort&order` | List (RBAC-scoped) |
| GET | `/papers/{id}`, `/papers/{id}/status`, `/papers/{id}/file` | Detail, progress, original file |
| POST | `/papers/{id}/reanalyze`, `/papers/{id}/approve` | Retry / approve for archive |
| DELETE | `/papers/{id}` | Delete (not approved papers) |
| GET | `/reports/{id}`, `/reports/{id}/insights` | Match report, preparation insights |
| GET | `/dashboard/stats` | Dashboard KPIs |

Access control: faculty see their own papers, department heads their department's, admins everything.
Papers a user may not see return `404`.

## Configuration Reference

All backend settings live in [`backend/app/core/config.py`](backend/app/core/config.py) and can be set via
environment variables or `backend/.env` — see [`backend/.env.example`](backend/.env.example).

| Variable                     | Default                                   | Description                          |
|------------------------------|-------------------------------------------|--------------------------------------|
| `DATABASE_URL`               | `postgresql+psycopg2://qpi:secret@localhost:5432/qpi_db` | PostgreSQL connection |
| `TASK_QUEUE`                 | `background`                              | `background` or `celery`             |
| `EMBEDDING_PROVIDER`         | `sentence_transformers`                   | or `hashing` / `mock`                |
| `EXACT_MATCH_THRESHOLD`      | `0.90`                                    | Exact repetition similarity          |
| `PARAPHRASE_MATCH_THRESHOLD` | `0.75`                                    | Paraphrase similarity                |
| `CONCEPTUAL_MATCH_THRESHOLD` | `0.60`                                    | Conceptual similarity                |
| `JWT_SECRET_KEY`             | dev-only value                            | Required when `ENVIRONMENT=production` |
| `CORS_ORIGINS`               | `http://localhost:3000,...`               | Browser origins allowed direct access |
